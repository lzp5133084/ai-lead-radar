# AI 客资雷达 · 真实采集本地版

这是在您电脑上运行的管理后台。输入地区和需求关键词，接入您有权使用的 RSS、公开网页、授权 API 或 Tavily 搜索 API，系统才能采集实际内容。没有数据时会如实显示 0 条，不会生成演示客户。

当前下载包已根据您的需求，预填“泸州保险配置需求”的地区、关键词与中国平安保险解决方案服务介绍。新建任务时可使用这些设置。来源仍需您合法连接后选择，定时采集默认暂停；预填设置不会生成客户或自动批准来源授权。简单操作见《泸州保险使用说明.txt》。

## 电脑上，三步启动

1. 解压整个文件夹到：`E:\Chat GPT6\AI_Lead_Radar_Real_v1\`。
2. 双击 **`启动客资雷达.bat`**。请保留打开的服务窗口。
3. 浏览器打开后，使用服务窗口显示的首次登录密码进入。首次密码也保存在 `data\首次登录.txt`；请妥善保管，并在登录后修改密码。

电脑页面地址是 **http://127.0.0.1:8765**。若浏览器没有自动打开，直接把这个地址粘贴到地址栏即可。Windows 64 位便携包自带 Python，正常使用无需安装编程环境、无需下载依赖。

已经使用旧版时：先关闭旧服务窗口，将新版解压到原来的位置，选择替换程序文件，再重新启动。原来的 `data` 文件夹请保留；新包不含业务数据或密码文件，不会要求重新建立客户库。更新前可先复制整个 `data` 文件夹留作备份。

## 手机上使用

1. 先关闭原来的服务窗口，再双击 **`启动手机局域网.bat`**。
2. 电脑和手机连接同一个可信 Wi-Fi。
3. 手机浏览器打开服务窗口打印的局域网地址，例如 `http://192.168.1.10:8765`。使用同一登录密码。

如果 Windows 弹出防火墙提示，只允许您信任的“专用网络”。如果打不开，检查手机是否使用了移动网络、路由器是否开启访客网络隔离，以及电脑是否进入睡眠。

局域网版使用普通 HTTP，适合可信的家庭或办公室局域网。请勿把端口转发到公网或在公共 Wi-Fi 开放它。这个交付包没有部署到公网。

## 第一次获得真实结果

1. 在“数据源”添加您有权使用的真实 RSS 地址、网页 URL 或 API 地址，填写来源名称和平台，确认具备合法访问与使用权限。您也可选择 Tavily 公开搜索 API，按《凭证与数据源清单.md》取得并在本机配置自己的 API Key。先使用免费额度，不必购买套餐。保存。
2. 在“采集任务”创建任务，填写行业、地区及关键词，把任务关联到对应数据源。例如，地区填“杭州，余杭”，关键词填“求装修，装修报价，找装修公司”。填写自己真正服务的地区与需求词；这些文字只是任务设置，不会生成客户。
3. 点击“立即采集”。到“运行日志”查看是否访问成功、读取多少内容、匹配多少内容、重复多少条，以及失败的原因。
4. 在“线索”查看匹配项的原始链接、来源、采集时间、发布时间、原文、分数和判断依据，点开原始链接核实。系统规则分仅帮助排序，不代表对方已同意营销或一定会购买。
5. 人工核实地区、实际需求、内容使用许可及联系方式的公开用途后，再审核跟进话术。搜索摘要须打开原文，并确认对方明确邀请咨询回复或商业联系。未获邀请时不要发送营销消息。话术只是待审核草稿，程序不会发私信、打电话或群发消息。
6. 按地区、分数、行业及状态筛选后导出 CSV。飞书需要您另行授权；配置完成后才会通过真实 API 写入指定多维表格。

**RSS、网页和 API 本身必须包含实际目标地区与实际需求。** 新闻摘要、行业资讯、推广内容即使出现“保险”或“装修”，也未必是客户需求；严格筛选后 0 条是正常结果。规则也可能误判，请人工核实后再把待审核内容当作客户线索。系统没有未经授权的小红书、抖音或视频号全网评论抓取功能。

Tavily 搜索模式按任务的地区和关键词查询真实搜索来源摘要，使用 basic 请求，每次最多20项，只读取来源内容，不使用生成式答案。保存的是搜索 API 返回的摘要及原始链接；页面会标明“搜索摘要，需核实原文”。此模式不提取联系方式，不搜索个人联系方式、病史或保单信息，跳过敏感内容和未出现邀请回复表达的内容；需人工打开来源核实需求、使用许可和发布时间。小红书、抖音、知乎、视频号等受限平台来源会排除。条件和搜索覆盖较窄，0条是可能的实际结果。

Brave 普通搜索套餐禁止将结果持久保存为数据库，普通 Key 无法用于本项目保存客资。高级入口需要另外获得书面存储授权并填入许可依据；旧版已经设置的普通 Brave 来源也会停止查询和保存。不得以勾选声明替代真实授权。[Brave 官方存储说明](https://api-dashboard.search.brave.com/documentation/resources/help-feedback)

1.0.2 修复了 VPN/代理将公开域名映射为特殊地址时误拦 Tavily 的问题。仅固定官方 `https://api.tavily.com/search` 使用标准、强制证书校验的 HTTPS 连接，遵循本机代理配置，禁止重定向和关闭证书校验。搜索结果链接只保存，不通过这个连接追踪或抓取；其他网页、RSS、通用 API 继续使用公开地址保护。网址中含凭证、本机域名和私网 IP 的链接仍拒绝。

## 各种状态是什么意思

| 状态或现象 | 应当怎样处理 |
|---|---|
| 未配置数据源 / 待连接 | 添加真实 URL 或授权 API；不会自动出现线索 |
| 采集完成，新增 0 条 | 先看访问是否成功和重复数量；无匹配地区、无意向、排除词命中或隐私限制也可能使内容不进入线索库 |
| 网页读取不到正文 | 检查 URL 是否无需登录即可访问；可填写页面正文的标签、`#id` 或 `.class`，本版不执行网页脚本 |
| 403、验证码、要求登录 | 停止使用该地址，改用合法授权 API 或允许使用的来源；程序不会绕过这些限制 |
| 来源被 robots.txt 禁止 | 尊重来源限制，改用对方允许的渠道；robots 允许也不等于获得商业使用许可 |
| 飞书待连接 / 同步失败 | 本地数据仍然保存；按《凭证与数据源清单.md》检查凭证、权限、表格列名及日志 |
| 手机打不开 | 确认已启动局域网版、同一可信 Wi-Fi、防火墙专用网络允许、电脑未睡眠 |

## 定时运行和数据保存

- 定时采集只在服务窗口保持运行、电脑开机且没有睡眠时工作。关闭窗口、关机或睡眠时不采集；重新启动后继续按任务设置运行。
- SQLite 数据保存在本程序的 `data` 文件夹。迁移或备份时，先关闭服务，再复制整个 `data` 文件夹。备份里包含您的任务、线索和本地设置，请限制访问。
- 默认保留期限为 90 天；过期的本地线索会清理。需要长期保存的资料先按自己的合规要求导出、审核和归档。
- 删除本地线索或清理过期数据不会删除已经写入飞书的记录。飞书及导出文件中的个人信息需要您分别管理。
- 本版是单管理员本地工具。没有虚构的 VIP 权限体系，也没有自动外呼、自动私信、自动发送消息。

## 联系方式和权限边界

程序以需求内容为中心。手机号、邮箱和微信号不会因为“公开可见”就被当作获客名单。只有发布者明确主动公开用于商业联系的联系方式，且有来源佐证，才进入人工审核流程；其他联系方式会掩码。请在原始页面核实本人发布、用途和时效。

保险任务用于主动公开的保险咨询或投保需求，识别到疾病、诊疗、残疾等敏感词的内容会跳过。请勿设置针对个人健康或其他敏感状况的营销任务；规则不能代替人工隐私审核。程序也不采集私聊、登录后私人内容、不绕过验证码或访问控制。对抓取和商业使用，您仍需具备来源许可或合法授权；添加来源时的确认不替代来源方授权。

飞书及数据源密钥仅在您本机服务端保存与使用，保存后不向网页前端回显。Windows 上直接填入后台的密钥使用本机用户的 DPAPI 加密保存；迁移电脑或 Windows 用户后，可能需要重新填写凭证。不要把密码、App Secret 或 API Token 发到聊天里。

## 忘记密码或给开发者运行源码

忘记管理密码时，先关闭服务。在本程序文件夹打开终端，运行下面的命令重置；新密码只显示在本地。重置密码也会让旧的登录会话失效。

也可以直接双击 **`重置本机登录密码.bat`**，随后用启动窗口的新密码登录。

```powershell
.\runtime\python.exe app.py --reset-password
```

源码版需要 Python 3.11 或以上，使用标准库，不需要 `pip install`：

```powershell
python app.py
```

局域网启动使用 `python app.py --lan`。默认只监听 `127.0.0.1:8765`，局域网模式监听 `0.0.0.0:8765`。

完整的数据源要求、飞书注册及授权清单见同目录 **《凭证与数据源清单.md》**。本包中的测试使用独立临时目录，测试数据不进入您的正常线索库。
